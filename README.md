### Hi there <img src="https://github.githubassets.com/images/icons/emoji/unicode/1f44b.png" width="22" height="22">, I'm Mthobisi Latha

Investment Portfolio Analyst & Data Scientist, I build production-grade AI and automation systems for institutional fund management. I work at the intersection of financial analytics, machine learning, and cloud engineering — turning manual analyst workflows into reliable, scalable pipelines.

#### <img src="https://github.githubassets.com/images/icons/emoji/unicode/1f680.png" width="20" height="20"> What I'm Building

- **AI-powered GIPS compliance checker** on Databricks (Python, Streamlit, Delta Lake, Claude/Databricks Foundation Models) — extracts rules from IMA mandate PDFs, auto-classifies report types (composite multi-manager comparisons vs. individual GIPS-compliant fund presentations) via a scoring-based detector module, and runs YAML-defined checks that return deterministic PASS/FAIL/BREACH results
- **Automated fund-data ingestion pipeline** integrating Microsoft Graph API + MSAL with Databricks — pulls performance reports from shared mailboxes across South African asset managers (Allan Gray, Coronation, Ninety One, and more) into Delta Lake
- **Multi-step AI investment report QC reviewer** — automated quality-control system for institutional portfolio reports covering benchmark detection, market value reconciliation, and attribution analysis
- **End-to-end CNN for image classification** (TensorFlow/Keras) — deep learning model reaching ~95% accuracy via hyperparameter tuning and GPU-accelerated training
- **Credit card fraud detection pipeline** — scalable Python ML pipeline (Random Forest, Logistic Regression) with engineered feature workflows that cut false positives by ~30%
